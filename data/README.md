# Data

The raw bank dataset is intentionally not included in this public repository.

To run the notebook or Python pipeline, place the dataset here as:

`Bank_Personal_Loan_Modelling.csv`

Expected original columns:

- ID
- Age
- Experience
- Income
- ZIP Code
- Family
- CCAvg
- Education
- Mortgage
- Personal Loan
- Securities Account
- CD Account
- Online
- CreditCard

The project notebook contains 5,000 customer records. The target is `Personal Loan`.
